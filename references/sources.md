## 后续修订（规范在 v1.0 基础上按实测与平台变化改动，需与此处同步）

| 编号 | 改动 | 依据 |
|---|---|---|
| U-3 | 「建议目录式带斜杠」改为「以路由实际返回 200 的形态为准」 | 实测：Astro 默认带斜杠；纯静态 `.html` 站带斜杠会 308 跳回；`trailingSlash: ignore` 下会产出 `/x` 与 `/x/` 两个 canonical 变体 |
| U-11 | 站内搜索结果页 / 筛选页从「robots 屏蔽」改为「允许抓取 + noindex」 | 被 `Disallow` 的页 Google 读不到 `noindex`，URL 仍可能被索引成空页 |
| T-5 | FAQPage 不再作为「拿富结果」的手段 | Google 于 2026-05-07 全量下线 FAQ 富结果（2023-08 起已限制为政府/医疗站；2026-06 移除 GSC 报告与 Rich Results Test 支持）。schema 本身未废弃，留着不报错不降权 |
| P-4 | 首批「20~50」改为「10~20，之后每批 ≤10、批间隔 ≥1 周」 | 与 `游戏站开发与部署` §2.3 对齐，避免两处数字打架 |
| I-6 | 60% 标注为经验阈值 | 无官方标准来源，仅用于发现过度优化形态，不作考核指标 |
| Z-1 判定 | 增加「不要只 grep 关键词」 | 关键词可能命中 meta description / JSON-LD / title，产生假通过 |
| C 章 | 新增性能阈值与第三方脚本规则 | 原 v1.0 完全未覆盖 Core Web Vitals，而它是真实排名因素，且广告站最易失分 |
| K 章 | 新增关键词地图 | 「一页一词」只有原则没有事实源，多人协作 / 程序化页面必然失效 |
| M 章 | 新增改版迁移流程 | U-4 只有「必须一一 301」的原则，缺可执行动作 |
| 第 11 章 | 新增收录异常排查 | 原文适用场景声明了该能力，正文无对应章节 |
| R-1 / U-8 / U-12 / I-12 / T-7 / C-3 / C-5 | 从本地 `seo1` / `seo2` cursorrules 与 Canva 内链模板中抽取可用项 | 两份 cursorrules 互为 95% 重复，且写成 Cursor 不解析的伪代码 DSL，只能当散文看；内容 9/10 已被本规范覆盖，故只抽净新增项 |

## 不采纳及原因（防止以后又被捡回来）

> 2026-11-09：原「关键词密度 1~3%」一条已删除，改判为 house 必检项，见上方修订表的 T-9 / T-9.1。

| 被否掉的写法 | 出处 | 否决原因 |
|---|---|---|
| FID 作为性能指标 | seo1 / seo2 §6 | 2024-03 起已被 INP 取代，现行指标见 C-1 |
| 所有 `<img>` 加 `loading="lazy"` | seo1 / seo2 §1 | 首屏 / LCP 图 lazy 会拖慢 LCP，与 C-3 冲突 |
| 内链一律用相对 URL | seo1 §4 | 与 Canva 模板「内链一律绝对 URL」正面矛盾；正解是全站统一且与 canonical 同形态（U-3） |
| `avoid urls.has("?")` | seo1 / seo2 §9 | 过严，该禁的是可索引的无限参数空间（U-7），不是问号本身 |
| FAQPage 用来拿富结果 | seo1 / seo2 §5 | 富结果 2026-05-07 已全量下线，见 T-5 |
| `headerToContentRatio() > 0.5` / `ensure cssHas("@media")` | seo1 / seo2 §10 / §8 | 不可执行的伪指标，混进硬规则会稀释重点 |
| 页尾 CTA 区再放一个 `<h1>` | Canva 内链模板 §2.13 / 示例 | 违反 T-2「h1 全页唯一」，且与同目录 seo1 自己的 `count("<h1>") == 1` 矛盾 |
| 「核心词重复 3-5 次」「每词 2-3 次」「锚文本 20/20/15/15/15/15」 | Canva 内链模板 §二 / §三 | 单页观察值当规范，会被机械执行成堆砌；已在 onpage-copywriting.md 改为区间与定性要求 |
| 「为重要内链加粗以提升权重」 | Canva 内链模板 §4.4 | 无依据，视觉强调不影响链接权重 |
| 把 16 区块结构当通用页面模板 | Canva 内链模板 §一 | 单页样本且是 SaaS 产品页，套到工具站会做出「很长很空」的页面，撞 P-3 |

⚠️ 本文件里的外部出处只作规则溯源，**不当作事实来源**。平台行为（富结果、GSC 界面、爬虫规则）变动频繁，执行前以官方文档实测为准；实测与本文冲突时改本文。
